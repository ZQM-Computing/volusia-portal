# Data Verification Checklist: Project Volusia

## Verification Protocol
All data entered into Project Volusia datasets must pass through this verification checklist before acceptance.

---

## Employer Data Verification

### Initial Source Check
- [ ] Employer exists and operates in Volusia County
- [ ] Official website located and accessible
- [ ] Careers/Employment page identified
- [ ] Physical address verified (Google Maps/Indeed/local business listing)

### Employee Count Verification
- [ ] LinkedIn company page checked (employee count range)
- [ ] Google Business profile reviewed
- [ ] News articles searched for layoffs/hiring
- [ ] SEC filings checked (if publicly traded)
- [ ] Local business directories referenced

### Pay Scale Verification
- [ ] Job postings checked on company website
- [ ] Salary data from Glassdoor/Indeed reviewed
- [ ] Benefits information located (if available)
- [ ] Pay scale validated against similar employers

### Sector Classification Verification
- [ ] Company website "About Us" reviewed
- [ ] Products/Services pages examined
- [ ] LinkedIn "About" section checked
- [ ] NAICS code researched (if available)

### Contact Information Check
- [ ] Careers email address tested (valid format)
- [ ] Phone number verified (active, not disconnected)
- [ ] Recruiting contact identified
- [ ] Application instructions clear and current

---

## Job Data Verification

### Listing Verification
- [ ] Original job posting URL accessible
- [ ] Posting date verified (not expired/stale)
- [ ] Position still being recruited for
- [ ] Application process functional

### Benefits Information Check
- [ ] Benefits listed on job posting
- [ ] Benefits page on employer site accessible
- [ ] Pay scale matches other listings from same employer

### Remote Eligibility Check
- [ ] Remote policy documented in listing
- [ ] Company remote work policy reviewed
- [ ] Job family typically supports remote work

---

## Cross-Reference Requirements

### Minimum Verification Sources
- [ ] **Primary Source**: Employer website or job board
- [ ] **Secondary Source**: LinkedIn, Indeed, company news
- [ ] **Tertiary Source**: Google Business, local directories

### Confidence Scoring
- **High (✓✓)**: 3+ consistent sources
- **Medium (✓)**: 2 sources, minor discrepancy
- **Low (-)**: 1 source, needs verification

---

## Staleness Indicators

### Red Flags
- No website updates in 6+ months
- LinkedIn page last updated > 1 year ago
- No job postings in 12+ months
- Recent news about company closure
- Disconnected phone numbers

### Green Flags
- Regular blog/news updates
- Active social media presence
- Current job postings
- Recent press releases
- Multiple employee posts on LinkedIn

---

## Documentation Requirements

### For Each Verified Datapoint
- Source URL(s) documented
- Verification date recorded
- Confidence level assigned
- Verifier name/initials (human review)

### For Conflicting Datapoints
- Both sources documented
- Discrepancy explained
- Decision documented (human override)
- Confidence level set to Low
