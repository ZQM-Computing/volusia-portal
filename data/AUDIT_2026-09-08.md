## Key Findings

### Critical Data Corruption
- `per_capita_income_acs` returns `-888888888` (sentinel value in cache)
- `pct_white_alone_acs` returns `579622.0` (population count instead of percentage)
- 9 demographic indicators have stale 2022-2023 vintage while economic has 2024

### All 5 Constituency Pages Have Hardcoded Data
- **HomePage**: `pci` variable maps to wrong indicator key
- **BusinessPage**: `businessFormation` and `industryMix` are derived estimates
- **ResidentsPage**: `costOfLiving` and `incomeTrend` were hardcoded arrays
- **TouristsPage**: `monthlyVisitors`, `Beach Flags`, `annualVisitors` are hardcoded
- **LeadersPage**: `investmentData`, `workforceData`, `permittingVelocity` are derived estimates

### Backend Endpoint Issues
- `/indicators.csv` works at `/indicators.csv` but NOT at `/data/indicators.csv`
- `/news.json` returns 404 — no news content management
- `/refresh` default token is `volusia-refresh-secret-change-me`
- CORS allows all origins (`*`)
- `cvb_hotels` table has 0 rows
- `datasets` table has 10 rows but all `content=""`

### Infrastructure Issues
- Docker Desktop stopped (backend runs natively via uvicorn)
- cloudflared tunnel stopped
- Hosts file has stale .228 entries (~34 lines)
- Ollama :11434 exposed to LAN without auth
- dist/data/ missing 19 cache files after build

### Gamification Non-Functional
- 2 users, 0 XP, 0 missions completed
- Pulse data stale (48h)
- `/gamification/missions` exists but never called from frontend
- Leaderboard shows only 2 users both at level 1
