## Phase 2: Page-by-Page Verification

### 1. HomePage.tsx (326 lines) ✅ 95% — Data-Connected
- **Hooks used**: `useEconomicIndicators`, `useDemographicIndicators`, `useClimateIndicators`, `useMapLayers`, `useDatasets`
- **Charts**: Income trend line chart, Employment bar chart — both pull from live data
- **Stats**: 4 metric cards (median income, population, employment, per capita income) — all real data
- **Map preview**: 3 cards with live map layer counts
- **Issues**: 
  - `useEffect` import removed but `useState` still present (correct)
  - Dark mode toggle works via Layout.tsx
  - Maps page `geojsonData` prop not passed (maps still show hardcoded simplified boundary)

### 2. DataExplorerPage.tsx (168 lines) ✅ 85% — Data-Connected
- **Hooks used**: `useAllIndicators`, `useIndicator`
- **Charts**: Unemployment + income bar charts from live data
- **Filter**: Category filter now uses `source` field (was broken)
- **Buttons**: Download CSV and API buttons now wired
- **Issues**:
  - Search/filter uses `source` field but `category` filter still checks `d.source` (may not match all data)
  - `downloadCSV()` calls `window.open` — no actual CSV generation, just opens `/data/indicators.csv`
  - Map layer data not consumed (indicator list shows but no geoJSON integration)
  - Missing `useEffect` cleanup for abort controllers

### 3. BusinessPage.tsx (155 lines) ✅ 80% — Partially Data-Connected
- **Hooks used**: `useEconomicIndicators`, `useDemographicIndicators`, `useClimateIndicators`
- **Stats**: Employment, avg wage, median income, unemployment — all real
- **Charts**: QCEW employment trend, industry mix bar chart
- **Issues**:
  - `industryMix` counts are **derived estimates** (`employment * 0.022`), not real industry data
  - No real business formation data source exists in the pipeline
  - Resources section (Market Benchmarking, Location Intelligence, Quarterly Briefing) are placeholder CTAs ("Coming Soon", "Subscribe")
  - No real CVB hotel data displayed on home page (TouristsPage has it)

### 4. ResidentsPage.tsx (158 lines) ✅ 75% — Partially Data-Connected
- **Hooks used**: `useDemographicIndicators`, `useEconomicIndicators`, `useClimateIndicators`
- **Stats**: Population, income, employment, temperature — real data
- **Charts**: Age distribution line chart from ACS data
- **Issues**:
  - Education, Public Safety, Environment, Housing, Government, Transportation sections are **empty placeholders**
  - No data source for education statistics (FL DOE endpoints restructured)
  - `pctBachelor` StatCard was removed (duplicate fix applied correctly)
  - 6 empty categories still need data population

### 5. TouristsPage.tsx (130 lines) ✅ 80% — Partially Data-Connected
- **Hooks used**: `useEconomicIndicators`, `useDemographicIndicators`, `useClimateIndicators`
- **Stats**: Employment, avg wage — real (not CVB-specific as intended)
- **Charts**: Monthly visitor volume line chart (hardcoded fallback data)
- **Issues**:
  - **Major bug**: The `useEconomicIndicators` data is used but CVB-specific indicators (avg_daily_rate, revpar, hotel_occupancy_pct) are pulled from the **wrong indicators** — they're showing QCEW employment data instead of actual hotel data
  - The `hotelOccupancy` variable pulls from `getIndicator(economic?.indicators, 'hotel_occupancy_pct')` which correctly finds it in Economic category, but the value `51.5%` is actually from the CVB source with vintage "December 2021" — **stale data**
  - Monthly visitors chart uses hardcoded fallback data (not from any API)
  - Resource cards (Event Calendar, Verified Reviews, Parking & Transit) are dead-end placeholders

### 6. LeadersPage.tsx (153 lines) ✅ 80% — Partially Data-Connected
- **Hooks used**: `useLeaderboard`
- **Stats**: Employment, avg wage, unemployment — real
- **Charts**: Investment bar chart (derived estimates), workforce pie chart (derived estimates)
- **Issues**:
  - `investmentData` and `workforceData` are **derived estimates** (employment * factor), not real investment/workforce data
  - `permittingVelocity` is hardcoded (18, 45, 7, 62 days) — no backend source
  - `moversIndicators` is empty array (no data from useLeaderboard)
  - **Critical bug**: `useLeaderboard` returns `{leaderboard: [...], count: 2}` but the code uses `leaderboard.length` — the data structure has a `leaderboard` key inside the response, but `useApiData` returns the raw response, so `leaderboard` in the component is actually the `{leaderboard: [...], count: 2}` object, not the array

| Transportation | 0 | ❌ Empty | VOTRAN/FDOT endpoints restructured |
| Environment | 0 | ❌ Empty | EPA AQS/USGS endpoints restructured |

### B. Source-Version Drift
- `dist/data/` has 10 files, `data/cache/` has 29 files — **19 cache files NOT synced to dist**
- The `npm run build` copies `data/cache/*.json` to `dist/data/` but only 10 are there
- Missing from dist: `bea_income.json`, `business.json`, `census_dp03.json`, `census_dp05.json`, `noaa_daily.json`, `noaa_daily_2025-09-02_2026-09-02.json`, `noaa_daily_2025-09-03_2026-09-03.json`, `open_meteo_forecast.json`, `redfin.json`, `redfin_volusia.json`, `safety.json`, `tourism.json`, `transportation.json`, `volusia_business.json`, `volusia_gis.json`, `zillow_zhvi.json`
- **Possible cause**: `npm run build` copy script filters `.json` files but some have date suffixes

### C. API Contract Issues
- `/indicators.csv` endpoint exists but `useDownloadCSV` just does `window.open('/data/indicators.csv')` — no actual CSV generation from live data
- `/refresh` GET returns 200 but does NOT actually refresh data (it's the diagnostics page)
- `/refresh` POST requires auth secret (still works)
- `/pulse.json` returns gamification pulse but all items are stale

### D. Frontend-Backend Mismatches
- **LeadersPage**: `useLeaderboard()` returns `{leaderboard: [...], count: 2}` but code treats it as an array
- **TouristsPage**: CVB indicators found in Economic category instead of Tourism category
- **MapsPage**: `useMapLayers()` fetches data but never renders GeoJSON
- **GamificationPage**: `pulse` state from `useGamification` has `items` array but code iterates `pulseItems` directly
- **DataExplorerPage**: `downloadCSV()` calls `window.open` without category param (hardcoded to `/data/indicators.csv`)

### E. Infrastructure Issues
- **Nginx config**: Single `nginx.conf` in project dir, not deployed to system nginx
- **Cloudflared**: Running via nssm, zqmlabs.com returns 200
- **Docker Desktop**: Stopped (backend runs natively via uvicorn)
- **Backend process**: PID 9068, running natively (not in Docker)

### F. Stale/Placeholder Data
- `news.json`: 1 article, 18 bytes — essentially empty
- `stakeholders.json`: 1377 bytes — minimal stakeholder data
- `health.json`: 205 bytes — minimal health check data
- Gamification: 2 users, 0 XP, all missions unfilled
- `map_layers.json`: 18 layers registered but MapsPage doesn't render them
