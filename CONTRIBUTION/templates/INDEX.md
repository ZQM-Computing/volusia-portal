# Contribution Templates — Project Volusia

> Reference for all 11 submission templates available in this directory.

## Available Templates

| Template | For | Description |
|----------|-----|-------------|
| `ANALYSIS_SUBMISSION.md` | Data analysis | Submit a new data analysis or interpretation |
| `CODE_INFRA_CONTRIBUTIONS.md` | Code/infra | Submit code changes, infrastructure updates |
| `COMMUNITY_INPUT.md` | Community | Submit community feedback or input |
| `CONSTITUENCY_CONTRIBUTIONS.md` | Constituency | Submit content for tourists, residents, business, or leaders |
| `DATA_SOURCE_SUBMISSION.md` | Data sources | Propose a new data source |
| `DIRECT_CONTRIBUTION.md` | Direct | Direct contribution to the project |
| `MAP_SUBMISSION.md` | Maps | Submit a new map layer or geographic data |
| `SCHOOL_PROJECT_SUBMISSION.md` | Education | Student school project submissions |
| `SOCIAL_MEDIA_INPUT.md` | Social | Social media content and outreach |
| `TOOL_SUBMISSION.md` | Tools | Submit a new tool or utility |

## Submission Process

1. Choose the appropriate template
2. Fill in all required fields
3. Submit via `CONTRIBUTION_LOG.md` (link from template)
4. Await review by the relevant team lead

## Guidelines

- All submissions are tracked in `CONTRIBUTION_LOG.md`
- Status flow: `PENDING → REVIEW → ACCEPTED | REJECTED`
- Templates use YAML frontmatter for metadata
- See `CONTRIBUTING.md` for pathway details
