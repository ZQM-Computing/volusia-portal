# BUSINESS OWNER CONTRIBUTION

Pathway B — Business Owner Contributor

Business owners contribute market data, sector benchmarks, local hiring patterns, and operational insights that help other businesses in Volusia County thrive.

## Submission Fields

| Field | Description | Type |
|-------|-------------|------|
| **Business Name** | Your business name (or anonymous) | Free text |
| **Sector/Industry** | Primary industry classification | Select from BLS sectors |
| **Data Type** | What you're contributing | Select |
| **Data Value** | The actual data point | Number + unit |
| **Source** | Where the data comes from | Free text + URL |
| **Vintage** | When this data was collected | Date (YYYY-MM-DD) |
| **Context** | Why this matters for other businesses | Free text |
| **Permission** | Can we publish this publicly? | Yes / No / Anonymous |

## Data Types

- **Employment figures** — Hiring, headcount, seasonal patterns
- **Revenue benchmarks** — Sector-specific revenue ranges (anonymized)
- **Operational costs** — Rent, utilities, supplies, payroll
- **Customer demographics** — Who your customers are (aggregate, not PII)
- **Supply chain** — Vendor relationships, delivery timelines
- **Technology adoption** — What tools you use and how
- **Market trends** — Local market shifts you've observed
- **Growth metrics** — Expansion plans, hiring projections

## Guidelines

- Contribute only data you're authorized to share
- Anonymization is encouraged for sensitive figures
- Include vintage dates so others can assess freshness
- All submissions are evaluated for quality (see gamification system)
- Business owners earn XP and quality tiers for verified contributions

# RESIDENT CONTRIBUTION

Pathway C — Resident Contributor

Residents contribute demographic observations, community needs, service feedback, and quality-of-life data that helps the county serve its people better.

## Submission Fields

| Field | Description | Type |
|-------|-------------|------|
| **Community** | Which community in Volusia County? | Select |
| **Data Type** | What you're contributing | Select |
| **Data Value** | The actual observation or data point | Free text |
| **Location** | Where is this happening? | Address/neighborhood |
| **Date** | When did you observe this? | Date (YYYY-MM-DD) |
| **Impact** | How does this affect residents? | Free text |
| **Category** | Housing, jobs, services, safety, health, education | Select |
| **Permission** | Can we publish this publicly? | Yes / No |

## Data Types

- **Housing conditions** — Availability, affordability, quality observations
- **Job market** — Hiring notices, employment barriers, training needs
- **Service quality** — Government services, healthcare, schools
- **Safety observations** — Traffic hazards, lighting, emergency access
- **Health access** — Provider availability, wait times, transportation
- **Education gaps** — School needs, adult education, digital literacy
- **Community needs** — What resources are missing
- **Demographic shifts** — Changes in neighborhood composition

## Guidelines

- All observations are valued regardless of formal data training
- Include specific dates and locations for accuracy
- Resident data is never sold or used for advertising
- Quality tiers apply — verified observations earn higher XP
- Residents earn XP and "Community Voice" missions

# TOURIST CONTRIBUTION

Pathway D — Tourist Contributor

Visitors contribute travel data, seasonal observations, experience ratings, and tourism industry feedback that improves the visitor experience in Volusia County.

## Submission Fields

| Field | Description | Type |
|-------|-------------|------|
| **Visit Period** | When did you visit? | Date range |
| **Data Type** | What you're contributing | Select |
| **Data Value** | The actual observation | Free text |
| **Location** | Where in Volusia County? | Select |
| **Accommodation** | Hotel, rental, camping, RV? | Select |
| **Spending** | Approximate total spend (optional) | Range |
| **Experience Rating** | Overall satisfaction (1-5) | Scale |
| **Recommendation** | Would you return? | Yes / No |
| **Permission** | Can we publish this publicly? | Yes / No / Anonymous |

## Data Types

- **Visitor volume** — Estimated counts by location/period
- **Accommodation data** — Occupancy, rates, availability
- **Experience ratings** — Quality of attractions, dining, activities
- **Seasonal patterns** — Weather, crowds, best times to visit
- **Transportation** — Parking, transit, traffic conditions
- **Business feedback** — Local business quality and service
- **Event data** — Festival attendance, event satisfaction
- **Safety observations** — Beach conditions, emergency services

## Guidelines

- Tourist data improves the visitor experience for all
- Seasonal patterns help businesses plan staffing and inventory
- All ratings are verified before publication
- Tourists earn "Explorer Visit" and "Community Voice" missions
- Visitor feedback drives the "Tourist Intelligence" dashboard

# INDUSTRY MOVERS CONTRIBUTION

Pathway E — Industry Mover Contributor

Investors, developers, government officials, educators, and nonprofit leaders contribute capital flow data, infrastructure assessments, policy metrics, and workforce development information.

## Submission Fields

| Field | Description | Type |
|-------|-------------|------|
| **Role** | Your role in the industry | Select |
| **Data Type** | What you're contributing | Select |
| **Data Value** | The actual data point | Free text |
| **Sector** | Which industry sector? | Select |
| **Geography** | County-wide or specific area | Select |
| **Timeframe** | Historical period or projection | Date range |
| **Impact** | How does this affect Volusia County? | Free text |
| **Permission** | Can we publish this publicly? | Yes / No / Verified Only |

## Data Types

- **Capital investment** — Commercial, residential, industrial (anonymized)
- **Infrastructure capacity** — Water, power, broadband, transportation
- **Permitting data** — Timelines, approvals, bottlenecks
- **Policy metrics** — Compliance rates, regulatory impact
- **Workforce development** — Training programs, apprenticeship data
- **Education pipeline** — Graduate counts, skill gaps, employment rates
- **Nonprofit capacity** — Service reach, funding, volunteer counts
- **Economic development** — Incentives, zone data, growth projections

## Guidelines

- Industry movers have access to sensitive data — handle with care
- Verified contributors get higher quality tiers and XP
- All data is evaluated for accuracy and freshness
- Industry movers earn "Sector Pioneer" and "Data Architect" missions
- Governor-level contributors earn bonus XP for policy documentation
